### 🎮 Камера (ПОЛНОСТЬЮ ГОТОВА)

#### Blueprints:
- `BP_RTS_CameraPawn` - основной pawn камеры
- `BP_RTS_GameMode` - игровой режим
- `BP_RTS_PlayerController` - контроллер игрока

#### Функционал камеры:
- ✅ Orthographic (изометрический) вид - Pitch=-50°, Yaw=45°
- ✅ WASD панорамирование (screen-space движение через YawPivot)
- ✅ Q/E ротация камеры
- ✅ Mouse Wheel зум (OrthoWidth: 8000-40000)
- ✅ Shift FastPan (ускорение движения)
- ✅ Map bounds clamping (границы карты MinX/MaxX/MinY/MaxY)
- ✅ **Edge Panning - ВСЕ 4 КРАЯ:**
  - Left edge (X ≤ 15px)
  - Right edge (X ≥ ScreenWidth - 15px)
  - Top edge (Y ≥ ScreenHeight - 15px)
  - Bottom edge (Y ≤ 15px)
  - Диагональное движение в углах

#### Компоненты:
- YawPivot/PitchPivot архитектура
- SpringArm → Camera
- FloatingPawnMovement

#### Карты:
- `Main.umap` - основная тестовая карта с Landscape

### Минимум для Week 3 (Selection & Orders):

Чтобы реализовать **Marquee Selection** и **Right-click move**, нужно:

#### 1. Placeholder Objects (тестовые объекты)
```
Простые геометрические примитивы вместо полноценных моделей:
- Cube/Cylinder - юниты (разных цветов для типов)
- Box - здания
- Простой материал с цветом команды
```

#### 2. Базовая система выделения
```
- Компонент для "выделяемых" объектов
- Визуальный индикатор (Decal или outline)
- Marquee box (рамка выделения)
```

#### 3. NavMesh
```
- Nav Mesh Bounds Volume на карте
- Запечь NavMesh
- Протестировать патфайндинг
```

```

   - Static, не двигается
   - Тоже "Selectable"
   - Разместить 2-3 штуки
```

#### Шаг 2: Настроить NavMesh (15-30 мин)
```
1. Nav Mesh Bounds Volume на всю карту
2. Press P чтобы увидеть NavMesh
3. Проверить что юниты могут ходить
```

#### Шаг 3: Реализовать Marquee Selection (1-2 часа)
```
1. Left Mouse Button + Drag → рисовать рамку
2. Проверить пересечение с объектами
3. Добавить визуальный feedback (highlight)
```

#### Шаг 4: Реализовать Right-Click Move (30-60 мин)
```
1. Right Click → получить точку на земле
2. AIMoveTo для выделенных юнитов
3. Простая формация (линия)
```

**Итого:** 3-5 часов работы → рабочий прототип с выделением и движением!
